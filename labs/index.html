01 / MEASURED WITH DPMS V1

Less input.
A lighter start.

Standard uses KV cache. Pro adds DPMS alongside KV cache to reduce input tokens and processing time.

Our re-measured v1 comparison found 85.5% fewer input tokens at the first planner call of each turn. Explore the numbers and the complete-session results.

02 / DIRECT PLASTICITY

Can AI grow

ONGOING RESEARCH

Direct Plasticity explores more adaptive AI: how experience might support useful memory, continuity, and improvement over time.

We are developing this direction in stages. DPMS v1 provides an input-token measurement; later stages need their own evaluation.
