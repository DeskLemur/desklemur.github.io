Test design
Two live runs of the same 12 scenarios, 14 turns per run. The model server restarted before each run to start with an empty KV cache. Both runs used KV cache throughout. The session totals pool calls with different levels of cache reuse.
First planner call
Counts use the model’s tokenizer before chat templating. The reduction compares sums across corresponding turns. The chart shows rounded per-turn averages.
Scope
Results apply to this test setup. Conversation histories can differ across the two runs. Task accuracy would require a separate comparison.
