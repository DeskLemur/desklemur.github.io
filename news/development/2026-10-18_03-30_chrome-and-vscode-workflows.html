Bring browser tasks and coding conversations into DeskLemurOS

18 Oct 2026 · 07:30 UTC

Explore how the Chrome Browser Bridge and VS Code integration connect everyday work to your DeskLemurOS agents, with an interface gallery to help you find your way around.

Browser work through the existing websurfing tool

The Chrome Browser Bridge connects Chrome to the DeskLemurOS desktop app on the same computer. An agent can open a page, read its visible content, and work with ordinary page controls through the app's existing websurfing tool. This supports tasks such as finding information on a website, following a link, or filling a form while checking the page after each action.

The bridge works with tabs it opens for the task. It does not read or close your other tabs. Interactive browsing requires a compatible desktop app, the extension, and its registered native messaging host. Search and page reading also have the app's existing retrieval and browser fallback paths.

For the source and unpacked installation steps, see the Chrome Browser Bridge repository. Setup includes loading the extension in Chrome, then using Tools → websurfing → Policy → Register with Chrome in DeskLemurOS.

Your agents in VS Code chat

The VS Code extension places DeskLemurOS agents in the chat model picker. Choose an agent and send a message from your editor; its turn runs in the DeskLemurOS desktop app on the same computer. Allow the workspace in DeskLemurOS, then review requested writes and commands in the app's Approvals view. The reply includes the agent's steps, answer, and changed files. VS Code's Stop control stops the turn.

Start with Easy Setup → Connections → Coding tools in DeskLemurOS, or visit the VS Code Marketplace listing. The extension source and setup guide explain the connection flow.

The homepage's interface gallery shows the app's workspace and controls; example-data screenshots are labeled. Explore the browser and editor integrations to choose your next workflow.
